# Break-Glass Access

Emergency access exists only to protect patients, products, people or critical operations.

- Require two authorized people whenever practical.
- Record reason, date/time, user identities and scope.
- Grant only the minimum required access.
- Prefer temporary credentials.
- Disable/revoke access immediately after use.
- Review every emergency access event.
- Link the event to an incident/deviation record where applicable.

Emergency access must never become routine administration.
