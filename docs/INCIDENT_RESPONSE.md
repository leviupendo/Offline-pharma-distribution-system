# Local Incident Response

1. Identify and record the event.
2. Preserve audit logs and relevant system state.
3. If compromise is suspected, isolate the affected workstation/server from the LAN.
4. Do not delete or alter evidence.
5. Notify the designated system owner and quality/security personnel.
6. Assess affected users, batches, inventory, orders and records.
7. If data integrity is uncertain, suspend affected workflows pending investigation.
8. Restore only from an approved known-good backup.
9. Record root cause and corrective/preventive actions.
10. Document final disposition and authorization to resume operations.
